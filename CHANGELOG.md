# Changelog

## 1.1.0

- Replace the minimal sidebar with a theme-aware instrument panel, tempo dial, numbered beat controls, clear playback status, and responsive layout.
- Add direct tempo entry, ±5 stepping, focused-panel keyboard controls, and tempo/tap commands.
- Add quarter, eighth, triplet, and sixteenth-note subdivisions, individual beat accents/rests, and a third Soft sound.
- Add mute/unmute, elapsed practice time, timed sessions with automatic stop, and measure counting.
- Add three built-in rhythms and named custom presets with persistence.
- Add English interface text, input validation, and migration of existing settings.
- Fix opening the plugin from a collapsed sidebar and accessing deferred views; fix missing playback icons.
- Clear audio/UI timers when stopping, closing the view, or disabling the plugin. Avoid overdue click bursts after a long suspension.
- Add regressions for view activation, settings migration, subdivision scheduling, muted beats, timer completion, and audio cleanup.
